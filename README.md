# Contoso Pet

Aplicativo de console em C# para organizar informações de animais que estão disponíveis para adoção.

No menu, dá para:

- listar os animais cadastrados;
- adicionar um cachorro ou gato;
- preencher ou editar informações;
- procurar gatos ou cães por uma característica.

O programa começa com alguns animais de exemplo e permite cadastrar até oito. Os dados ficam na memória enquanto o aplicativo está aberto; ao fechar, eles não são salvos.

## Conceitos de C# praticados

- variáveis e tipos de dados;
- condicionais com `if` e `switch`;
- laços `for` e `do while`;
- arrays multidimensionais;
- leitura e escrita no console;
- validação de entradas com `int.TryParse`.

## Requisitos

- .NET 10 SDK

## Como executar

Na pasta do projeto, rode:

```bash
dotnet run
```
